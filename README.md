# Skolenu gala rezultātu kalkulātors

Programmā var ievadīt skolēnu skaitu un kritētriju skaitu līdz 20.
Tad secīgi jāievada katra kritērija smagums (5-100%), skolēna vārds un katra skolēna rezultāts (1-10) katrā kritērijā.

Kad viss info. ievadīts, programma izvada visus skolēnu gala rezultātus.
Gala rezultāti rēķināti pēc formulas:
Gala vērt. = K(1) * S(1) + K(2) * S(2) ..., kur K(n) ir kritērija iegūtais vērtējums un S ir kritērija smagums/100.
